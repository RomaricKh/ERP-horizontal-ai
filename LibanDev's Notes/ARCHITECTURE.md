# Architecture Overview

## Technology Stack
- **Frontend**: JavaScript (Vite)
- **Backend**: PHP
- **Database**: SQL

## Directory Structure
- **src/**: Source code for both frontend and backend
- **tests/**: Unit tests for both frontend and backend
- **database/**: Database schema and migration files
- **docs/**: Documentation for the project

## Development Environment
- **Frontend**: Run `npm install` and `npm run dev`
- **Backend**: Run `composer install` and `php -S localhost:8000`

## Testing
- **Frontend**: Run `npm run test`
- **Backend**: Run `phpunit`

## Deployment
- Deploy frontend to a static file server
- Deploy backend to a PHP server

# Security
- Ensure all dependencies are up to date
- Use HTTPS for all communication
- Implement proper authentication and authorization

# Maintenance
- Regularly update dependencies
- Monitor logs for errors and issues

# Lessons Learned
- Always test thoroughly before deployment
- Use version control for all code
- Document all changes and decisions
